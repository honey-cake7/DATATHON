📈 RECOMMENDED WORKFLOW
═══════════════════════════════════════════════════════════════════════════════

PHASE 1: UNDERSTANDING (Day 1-2)
  1. Read README.md and SETUP.md
  2. Install requirements: pip install -r requirements.txt
  3. Run notebook: jupyter notebook notebooks/01_image_dehazing_pipeline.ipynb
  4. Follow through all 7 sections (each has executable code)

PHASE 2: DATASET & EVALUATION (Day 2-3)
  1. Download benchmark datasets:
     - I-Haze: https://github.com/cszn/NTIRE2018
     - N-Haze: https://nhaze.github.io/
     - Dense-Haze: https://www.dropbox.com/sh/86b86d3n1g6b9lx
  2. Extract to data/raw/{I-Haze,N-Haze,Dense-Haze}/
  3. Run batch processing:
     python scripts/utilities.py process --input data/raw/I-Haze --output results/

PHASE 3: EVALUATION & ANALYSIS (Day 3-4)
  1. Calculate metrics:
     python scripts/utilities.py evaluate --dehazed results/ --ground-truth data/
  2. Create visualizations:
     python scripts/utilities.py compare --original data/raw --hazy X --dehazed results/
  3. Compare models on same dataset
  4. Analyze hallucination potential

PHASE 4: DEPLOYMENT & PRESENTATION (Day 4-5)
  1. Test web dashboard: python web/app.py
  2. Prepare performance visualizations
  3. Document key findings
  4. Prepare viva explanation
